# nixpkg-plot

Nix packaging scaffold for `@os-eco/plot-cli` (Typed, queryable, JSON-backed coordination object for multi-agent work).

## Outputs

- `default` (`out`): `plot` (long-form binary)
- `pt`: `pt` (short-form alias binary)

## Local use

From this checkout, run `nix run . -- --help`, or install with
`nix profile install .`.
